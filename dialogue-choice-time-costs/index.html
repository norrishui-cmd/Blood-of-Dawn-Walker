Can Dialogue Choices Cost Time?

Yes. Certain dialogue choices have a visible time cost.

Officially sourcedConcrete answer

Direct answer

Yes. Certain dialogue choices have a visible time cost.

PlayStation’s developer preview specifically includes certain conversations among the major actions that can move the clock. This means talking is not always mechanically free.

How to use this information

Read the cost prompt before selecting time-consuming dialogue, especially when several leads compete for the same day or night.

Evidence boundary

Most dialogue costs and their consequences are intentionally undisclosed.

Planning rule

Apply the can dialogue choices cost time? answer together with three checks: which form Coen currently has, how many hourglass units the next action shows, and which other thread would be delayed. Free exploration and charged quest actions are different categories, so route advice should never deduct time merely because a player walked, searched, or opened the map.

PlayStation Blog developer preview. Checked 2026-07-25. This guide separates published facts from details that still require the release build.
