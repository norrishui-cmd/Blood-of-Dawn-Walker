Does Learning Skills Cost Time?

Some abilities can cost time to learn.

Officially sourcedConcrete answer

What is confirmed

Some abilities can cost time to learn. The developer preview identifies learning particular abilities for the skill tree as one of the actions that can visibly advance the clock.

Why players search for this

Build planning therefore involves both skill points and, for some abilities, time-budget tradeoffs.

What this page does not claim

The game has not published a complete list of time-costing skills or their exact hourglass values.

Planning rule

Apply the does learning skills cost time? answer together with three checks: which form Coen currently has, how many hourglass units the next action shows, and which other thread would be delayed. Free exploration and charged quest actions are different categories, so route advice should never deduct time merely because a player walked, searched, or opened the map.

Source

PlayStation Blog developer preview. Checked 2026-07-25. This guide separates published facts from details that still require the release build.
